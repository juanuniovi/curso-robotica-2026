# Modelos de arquitectura SysML

`SistemaUGV.slx` vive aquí — es un archivo único, compartido por todo el equipo.

1. Copiar la versión base desde [`base/modelos/SistemaUGV.slx`](../../base/modelos/) (generada con `crear_SistemaUGV.m`) a esta carpeta, una sola vez.
2. A partir de ahí, trabajar siempre sobre esta copia. No modificar el original de `base/`.
3. Al ser un archivo binario, coordinar entre roles quién lo edita en cada momento para evitar conflictos de fusión — ver la política de ramas y commits en la [página del curso](../../index.html#repositorio).
